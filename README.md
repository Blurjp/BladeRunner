# 雨港 · RAINHARBOR

一个原创的中文赛博朋克侦探 RPG 原型。故事发生在 2089 年的雨港，调查员林渡需要查明记忆档案员林弥的死亡真相，并决定合成人证人的未来。

## 运行

需要 Node.js 20.19+ 或 22.12+（已在 Node.js 24 验证）。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173 --strictPort
```

浏览器访问开发服务器的 5173 端口。生产构建使用 `npm run build`，本地预览使用 `npm run preview`。

## 已实现

- 四个可随时切换的街区：旧港、夜市、白噪诊所、天穹大厦。
- Canvas 绘制的动态雨夜城市、不同街区建筑与灯光、可移动的调查员。
- WASD / 方向键移动，靠近地点按 E 交互；也支持点击地图或地点按钮。
- NPC 对话、9 条可归档证据、四位密码解密、证据驱动的三项推理。
- 一个可完整结案的案件、两种有不同后果的叙事结局。
- 修理电台和面馆支线、信用点、合成雨声开关。
- 自动本地存档、存档损坏恢复、带确认的重置、移动端界面。

没有外部图片、字体、API、数据库或账号需求。画面由代码绘制，环境音由 Web Audio 合成。存档保存在当前浏览器的 localStorage，不跨设备同步。

## 验证

```sh
npm test
npm run build
npm run test:e2e
```

浏览器测试默认使用 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 指定其他 Chromium 可执行文件。端到端测试自动启动开发服务器，验证完整调查、密码错误重试、推理错误重试、两个结局、存档恢复、重置、移动端布局和键盘移动。

案件、地点、对话与证据定义在 `src/game.js`；界面和交互在 `src/main.js`；城市绘制在 `src/city.js`；布局在 `src/style.css`。后续可扩展更多案件、人物关系和地图。

本项目使用原创世界、人物和剧情，只借鉴赛博朋克与黑色侦探类型的氛围，不使用《银翼杀手》的角色、素材或故事。
